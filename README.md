# Matías Romero, Oaxaca — Sitio de divulgación cultural

Este repositorio contiene el sitio estático de divulgación histórica y cultural sobre el municipio de Matías Romero, Oaxaca. El objetivo es ofrecer contenido verificado, neutral y orientado a la preservación del patrimonio local: historia, tradiciones, participación en la Guelaguetza, y un archivo visual colaborativo.

Características principales:

- Sitio estático generado con Astro y estilos con Tailwind CSS.
- Páginas: Home, Historia, Origen, Quién fue Matías Romero, Cultura/Guelaguetza, Galería, Actualidad, Fuentes, Contacto, Privacidad, Licencia.
- Metadatos y JSON-LD básicos para SEO; sitemap y robots incluidos.
- Banner de política de privacidad al ingresar (aceptación local mediante localStorage).
